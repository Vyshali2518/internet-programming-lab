INTERNET PROGRAMMING LAB — EXPERIMENTS 1 TO 11

Every experiment is a separate standalone HTML file. Each file contains its own HTML, internal CSS, and JavaScript.

RUNNING:
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open Experiment_1_Library.html (or any other experiment).
4. Right-click -> Open with Live Server, or open the HTML file directly in a browser.
5. Test the search controls, favourites, and booking/order forms.

IMPORTANT:
These are front-end demo websites. Favourite items and demo activity are stored in the browser's localStorage. They do not connect to real booking providers, a database, or a payment gateway. Internet access is needed for remote images.
